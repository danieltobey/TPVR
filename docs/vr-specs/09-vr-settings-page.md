# 09 VR settings page

**Status:** 🟡 Built.

## Required behaviour
1. Sections, in order: View · Movement & Turning · Cutscenes · HUD · Lighting · Combat · Performance · PC Display (PC only).
2. Every description is at most two sentences and states the default ("On by default." / "Off by default." / "Default: 90 cm.").
3. Multiple-choice settings name the default first, then one short line per option.
4. Settings that depend on another are greyed out when it doesn't apply (e.g. TV Size outside TV mode; first-person-only settings in third person).
5. "(Experimental)" goes at the end of a name.
6. Always-on fixes (object lighting, sun-glare dimming off, sky, audio) have no setting.

## Verification
Walk the page in the headset: order, wording, defaults and greying match this spec. 🟡
